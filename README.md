# English Adventure MVP
1. Crie projeto no Supabase e execute `supabase-schema.sql` no SQL Editor.
2. No Supabase Settings > API, copie Project URL e `service_role` (segredo).
3. Suba os arquivos deste projeto a um repositório GitHub.
4. Importe o repo no Netlify; publish directory `.`; functions `netlify/functions`.
5. Netlify Site configuration > Environment variables: `SUPABASE_URL` e `SUPABASE_SERVICE_ROLE_KEY`.
6. Deploy. Teste cadastro e confira tabela `public.leads` no Supabase.
